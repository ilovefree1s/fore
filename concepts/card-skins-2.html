FORE card skins, round 2

Six different directions from the last batch. Less "paper texture", more character. Same content on every card: pile label, title, format tag, points, body with labeled lists, footer. All built-in fonts, so any of them works offline as-is.

1. Hero Icon big illustration up top, title under it

Each card gets a big picture in a colored header, like a modern party card game. The example uses emoji as stand-ins. The real version would use a set of flat icons drawn for each card: a wolf, an air horn, a foot kicking a ball, a 7 iron. The picture is what makes each card feel different from the next.
